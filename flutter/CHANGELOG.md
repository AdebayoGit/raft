## 0.0.1

Initial preview release.

* Offline-first raw key-value and typed collection APIs.
* Durable writes, batch operations, prepared collections, and cached reads.
* Predicate queries, optimistic transactions, collection observers, and live queries.
* Android, iOS, and macOS native libraries powered by the Rust core.
* Thread-safe transaction handles and safe null/empty FFI input handling.
* Observer resynchronization through `MutationKind.resyncRequired`.
